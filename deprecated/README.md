# Deprecated Files

This folder contains files that were moved during the refactoring on 2025-08-21.

## Structure

### `/orchestrators/`
- `orchestrator_v3_agentic.py.original` - Original V3 orchestrator before refactoring to use shared tools
- `orchestrator_v4_proposal.py.original` - Original V4 orchestrator before refactoring to use shared tools

### `/tests/`
- Various test files that were created during development
- Root-level test scripts that should be in the factory_tests folder
- `test_shared_tools.py` - Test script for shared tools architecture
- `test_proposal_fix.py` - Temporary test for proposal fixes
- `test_trace_v4.py` - V4 tracing tests
- `test_v4_inventory_integration.py` - V4 inventory integration tests
- `simple_verify.py` - Simple verification script
- `verify_search_functionality.py` - Search functionality verification

### `/ingestion_scripts/`
- `ingest_inventory_data.py` - Initial inventory ingestion script
- `ingest_merged_cells_data.py` - Script for handling merged Excel cells
- `ingest_sheet2_data.py` - Script for ingesting Sheet2 data
- `reingest_all_inventory.py` - Script to reingest all inventory data

### `/ui_reviews/`
- JSON files from UI design reviews
- Generated by the design review system

### `/logs/`
- `app_output.log` - Application output logs

### `/backups/`
- Timestamped backups of orchestrator files before refactoring

### Other Files
- `base_tool.py` - Attempted mock for agents module (not needed)
- `migrate_to_refactored.py` - Migration script (no longer needed)
- `sample_inventory.json` - Sample inventory data

## Note
These files are kept for reference but are no longer actively used in the application.
The refactored code uses:
- Shared tools architecture in `/factory_automation/factory_agents/tools/`
- Refactored orchestrators: `orchestrator_v3_agentic_refactored.py` and `orchestrator_v4_proposal_refactored.py`
- Compatibility wrappers for backward compatibility
